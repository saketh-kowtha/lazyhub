Keybindings

Every key in every view. Press ? inside lazyhub for context-aware help.

Global — works everywhere

TabNext pane
Shift+TabPrevious pane
g h / p / i / b / a / nGo to Home / PRs / Issues / Branches / Actions / Notifications (a which-key popup lists them after g)
Ctrl+AOpen AI assistant overlay (read-only)
,Settings
: / Space SpaceCommand palette (fuzzy match, recent actions first)
q / EscBack one level; q quits at the root, Esc never does
?Toggle context-aware help overlay
rRefresh current pane (bypass cache)
oOpen current item in browser
/Fuzzy search within current list
j / ↓Move cursor down
k / ↑Move cursor up
ggJump to top of list
GJump to bottom of list
yCopy URL of selected item to clipboard
Ctrl+DWrite a local debug-state dump

Pull Requests

⎇ PR List
EnterOpen PR detail view
dOpen diff view
bCheckout PR branch locally
mMerge (pick merge/squash/rebase)
MToggle auto-merge (or toggle merged filter when unavailable)
aApprove PR
xRequest changes
XClose PR
nCreate a new PR
lEdit labels (multi-select)
AEdit assignees (multi-select)
RRequest reviewers (multi-select)
f / O / CCycle filter (open → closed → merged) or toggle open / closed
s / @Cycle PR scope / filter by author
⎇ PR Detail
dOpen diff view
vOpen comments view
cEnter checks navigation (Enter log, o browser, Ctrl+R re-run, Esc exit)
CResolve conflicts, or open Actions for this branch
D / BToggle draft state / change base branch
EOpen first changed file in $EDITOR
m / MMerge PR / toggle auto-merge
a / x / XApprove / request changes / close PR
l / A / REdit labels / assignees / reviewers
⎇ Diff View
j / kScroll lines down / up
]Jump to next file
[Jump to previous file
}Next comment thread
{Previous comment thread
n / NNext / previous search match
t / TJump to file / toggle file tree
g lGo to line
cComment on cursor line (replies when the line has a thread)
e / Ctrl+XEdit / delete your comment on the cursor line
vSwitch to comments view
wToggle split / unified view
EOpen cursor line in $EDITOR
ARun AI code review of the diff
ggJump to top
GJump to bottom
EscBack to PR detail
💬 Comment Compose & Threads
TabCycle comment type / next field
Ctrl+EOpen $EDITOR for full body
Ctrl+G / Ctrl+EnterSubmit comment
z / J / fIn comments view: resolve thread / jump to diff / filter
EscCancel
