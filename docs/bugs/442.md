# listReleases and listGists pass arguments gh rejects (#442)

- **Area:** executor (actions, misc)
- **Symptom:** Calling `listReleases` or `listGists` fails at the `gh` CLI: `gh release list` rejects the `--json` field `url`, and `gh gist list` has no `--json` flag.
- **Root cause:** Both functions were written with argument shapes gh does not accept. Nothing in the UI calls them, so the failure was never reached.
- **Fix:** Delete `listReleases` (`src/executor/actions.js`) and `listGists` (`src/executor/misc.js`), along with their re-exports, mocks and tests. No remaining references.
- **Regression test:** None. The functions and their tests were removed. `grep -rn "listReleases\|listGists" src bin` returns nothing.
