# Published npm build ignored --version/--help and started the TUI (#514)

- **Symptom:** `lazyhub@26.6.2` from npm started the TUI for `--version`, `--help` and `doctor`, and crashed with Ink's raw-mode stack without a TTY. Nothing in the release path would have caught it.
- **Root cause:** the packed-install smoke only checked `--version` loosely and `doctor`; it never asserted `--help` or unknown-flag behaviour, and was not run before `npm publish` in `release.yml`.
- **Fix:** `scripts/packed-install-smoke.mjs` now asserts, on the installed tarball with a temp HOME and non-TTY stdin, that `--version` prints the `package.json` version (exit 0), `--help` exits 0 with "Usage:", and an unknown flag exits 2 with usage, none starting the TUI. CI already runs the script on every PR; `release.yml` now runs it before publish. Homebrew formula `test do` (expects `--version` exit 1) is in the separate tap repo and needs a follow-up there. Regression gate: `node scripts/packed-install-smoke.mjs`.
