# `lazyhub status --format json` prints plain text on a cold cache (#519)

- **Area:** cli, status
- **Symptom:** On a cold cache (no cached PRs or notifications), `lazyhub status --format json` printed `lazyhub: no data - open the app once`, which is not valid JSON for machine consumers.
- **Root cause:** `formatStatus` in `src/cli/status.js` returned the text cold-cache line before checking the format, so the JSON branch never ran for a null summary.
- **Fix:** When `!summary` and `format === 'json'`, `formatStatus` returns `{"schema_version":1,"counts":null,"cache_age_seconds":null,"reason":"no_cache"}`. Tmux and starship output is unchanged, and the exit code stays 0. `docs/CONTRACT.md` documents the new cold-cache behavior.
- **Regression test:** `src/cli/status.test.js` › prints a JSON object with reason on a cold cache in json format (failed before the fix with `Unexpected token 'l'`). Guards: `src/cli/status.test.js` › keeps the cold-cache text line for tmux and starship formats; does not add a reason key to warm json output.
