# PR list preview covered the list and Esc dismissal reset on every cursor move (#461, #504)

- **Symptom:** the preview popover floated over rows 2-6 at full row width, masking their titles; Esc hid it but the next `j` brought it back; `[layout].preview_panel = false` did nothing; at 80x24 after `G` it drew a line wider than the terminal (#504).
- **Root cause:** `list-view.jsx` anchored the popover over the rows and masked the covered titles; `list.jsx` cleared the dismissal on every cursor change.
- **Fix:** the preview is a side panel: rows are narrowed to leave its columns free, so it never covers a PR, and it is only shown when the pane is wide enough for both. Dismissal is sticky; `p` toggles it, and `preview_panel = false` starts it dismissed. Row masking is removed. The `2 G` at 80x24 pin in `random-keys` is removed, so the fuzz now covers it.
- **Regression tests:** `src/features/prs/list-view.test.jsx` (preview panel), `src/features/prs/list-paging.test.jsx` (dismissal).
- **Not done:** `p` is a fixed key, not a registry action (adding one touches the config schema, defaults and help).

## Review follow-ups
- `p` is now the registry action `pr.preview` (help, footer and remapping work); `legacy-defaults.js` regenerated.
- With the panel hidden, the focused PR's full title shows in the status line.
- The panel width follows `[layout].preview_width`.
