# Dashboard Enter opened items in the launch repository (#493)

- **Symptom:** selecting a PR/issue in a dashboard section with `filter.repo = "other/project"` and pressing Enter loaded that number from the launch repository (wrong item, or a failure).
- **Root cause:** `TabPane` fetched from `pane.filter.repo || repo` but reported no repository; `TabView` forwarded only item and kind, so `app-views` passed the global `repo` to the detail, diff, comments and conflict views.
- **Fix:** `TabPane` reports its resolved repository, `TabView` passes it to `onOpenItem`, and the selected item carries it as `_repo`; `app-views` uses `selectedItem._repo || repo` for every item view, so it also survives diff/comments and Esc back.
- **Regression test:** `src/focus-repository.test.jsx` (PR and issue variants).
