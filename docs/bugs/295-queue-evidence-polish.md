# Review queue and evidence polish from the Alpha journey (#295)

- **Area:** app (review queue, evidence view, help overlay, status bar, PR search)
- **Symptom:** six defects found by the Alpha journey PTY gate: (1) the evidence view said "Attention: none" for a PR the queue placed in "Needs my review" via a team; (2) at 80x24 the queue's `?` help hid the queue's own keys behind "+5 more"; (3) at 80 columns the scope line lost "read-only" and the why strip was cut; (4) `+` was silently ignored while a refresh was in flight; (5) the bottom status line showed the pane the queue was opened from (`focus · acme/platform ⟳ 10s ago`); (6) the PR search box looked as if it held a literal `/`.
- **Root cause:** (1) the single-PR read cannot know a team request matched the viewer; only the queue's review-requested search does, and the evidence derived its reasons without that. (2) help rows were in registry order, shared list verbs before the view's own. (3) fixed strings with no width budget. (4) the `busy` guard returned early. (5) the queue was rendered with the previous pane's status props. (6) the `/` is the prompt glyph beside an empty input (no keypress leak, checked by test); the placeholder made it read as typed text.
- **Fix:** (1) the queue record's `review_requested` reason is passed to `loadEvidenceDetail`, which re-derives attention and group with the same `attentionReasons`/`queueGroup` as the queue; the row says "via team @slug". (2) `contextHelpRows` lists the view's own actions first; the help drops its padding when that is what lets all own keys show. (3) `scopeLine` and `whyLine` take a width and drop the least important text first (explanation, then `s:` hint; seen, mergeability, CI, head). (4) a `+` during a fetch is remembered and runs when it ends. (5) the status bar has a `queue` pane and `hideAge`. (6) no behaviour change needed; test pins that the box opens empty.
- **Regression test:** `src/executor/evidence-detail.test.js` (team request), `src/review-queue.e2e.test.jsx` (queue record passed to evidence), `src/app-panels.test.jsx` (own keys first at 80x24), `src/features/queue/view.test.jsx` (scope line, why strip, queued `+`), `src/components/StatusBar.test.jsx`, `src/features/prs/list-paging.test.jsx` (search box opens empty), `test/pty/alpha-journey.js` (80x24 end to end).
- **Sibling sweep:** the own-keys-first help order applies to every view (the PR list 80x24 golden was updated); other panes' status bars unchanged.
