# R10 shell, first slice: the frame was pasted into every view branch (#488)

- **Area:** app
- **Symptom:** Sidebar x5, StatusBar x8 and FooterKeys x8 were copied across `app-views.jsx`; the scope chip expression was pasted eight times; `appCtx` was rebuilt on every App render; the prefix and leader timers lived in `app.jsx`.
- **Root cause:** each view branch built its own frame, so a layout change had to be made in many places.
- **Fix:** `src/shell/Shell.jsx` renders the frame once; `src/shell/scopeIndicator.js` and `src/shell/useChords.js` own the chip text and the 1.5 s chord windows; `appCtx` is memoised. Rendering and key behaviour are unchanged.
- **Regression test:** `src/shell/shell.test.jsx`; the existing screen snapshots, PTY flows and fuzz run unchanged.
- **Sibling sweep:** all views in `app-views.jsx` use the shell. Not done yet (left on #488): overlays layered over live panes, the `onPaneState` store, the width-budget helper, a scrolling help overlay and the single navigation store.
