# Review story: guided walkthrough of a PR diff (#362, first slice)

- **Area:** prs
- **Symptom:** a 40-file PR from a coding agent is reviewed in file-alphabetical order, so the reader meets callers before definitions and tests before the code they test.
- **Root cause:** the diff view had no grouping or ordering of changed files; the only navigation was next/previous file and a tree.
- **Fix:** `s` on a PR (detail view) opens the review story (`src/features/prs/story/`). `classify.js` and `build.js` are pure and deterministic: files are grouped into 3 to 7 steps (core change, call sites, config and docs, tests, noise) from path, extension, change size and, when known, import evidence; each step says why. `n`/`p` move between steps, `j`/`k` between files, Enter opens the existing diff at that file (`PRDiff` `initialFile`), Esc in that diff returns to the story at the same step and file. The noise step is collapsed but counted and expandable. "Since your last review" comes from `src/executor/pr-story.js` (the viewer's latest submitted review commit compared with the head): files changed since, or an explicit "unknown" with the reason (force-pushed away commit, no recorded commit). No file is dropped: every step list is windowed with "N of M", the file list is walked page by page with visible progress, and a failed or capped list says so.
- **Regression test:** `src/features/prs/story/build.test.js`, `StoryView.test.jsx`, `open-at-file.test.jsx`, `src/executor/pr-story.test.js` (new feature: no earlier red state).
- **Sibling sweep:** the story is read-only; no mutation flow or approval stage is touched.

## Not in this slice (Part of #362)

- AI ordering and one-line AI step summaries (later slice; must follow the `src/ai` isolation and be labelled as AI).
- Risk markers (auth, exec, deleted tests, public API) and formatting-only hunk detection. Noise here is path-based plus pure renames only, so a hunk with a semantic change is never hidden.
- Symbol-level dependency ordering. Import evidence is supported by `buildStory({ imports })` but the view does not fetch patches (3,000 patch fetches would break the speed budget), so ordering uses path, size and change type.
- Force-push fallback is limited to the compare answer: a rewritten history reports "unknown" or an approximate file-level comparison, never a silent guess.
- Entry from the PR list (`s` there already cycles the scope) and the command palette.
