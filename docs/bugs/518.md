# `lazyhub --mcp` printed prose to stdout and started an interactive login (#518)

- **Symptom:** with no GitHub login, `lazyhub --mcp` wrote "Not authenticated..." / "Starting login..." to stdout (a protocol violation for MCP stdio) and could start `gh auth login`.
- **Root cause:** `runMcpServer()` called the TUI `bootstrap(null)`, which prints to stdout, runs the interactive login flow and the repo picker.
- **Fix:** new `headlessPreflight()` in `src/bootstrap.js` (gh present, host selection, `checkAuth`, repo from remote or saved config) never prompts, prints or spawns a login. `runMcpServer()` writes one line to stderr and returns exit 1 on failure; stdout carries JSON-RPC only. The headless path also no longer writes the default config. Regression tests: `src/cli/mcp-server.e2e.test.js` (built `dist/lazyhub.js`, temp HOME, fake gh: unauthenticated, gh missing, authenticated) and `src/cli/mcp-server.test.js`.
- **Threat model:** no new surface; removes an interactive spawn from an agent-callable path.
