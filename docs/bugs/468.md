# Merge and review flows: raw CLI flags, 5 keystrokes to merge, Enter does not approve, inconsistent chrome (#468)

- **Area:** prs
- **Symptom:** The merge picker listed `--merge / --squash / --rebase` and the confirm read "Merge PR #142 via --merge?". A merge took `m`, Enter, Enter, Left, Enter. Enter on the approve box did nothing (Ctrl+G only). The commit-message step had no input box and no PR title. Dialogs used different borders, padding and hard-coded colours.
- **Root cause:** `MERGE_OPTIONS` (`list-row.jsx`, `detail.jsx`) used the CLI flag as the label; `OptionPicker` always opened a message step after Enter; `ConfirmDialog` defaults to No; `FormCompose` text fields only advanced to the next field on Enter; `ConfirmDialog` hard-coded `#f85149` / `#3fb950`.
- **Fix:** Human labels ("Create a merge commit", "Squash and merge", "Rebase and merge", "... (bypass branch protection)") with a shared `mergeMethodLabel`; the list confirm now reads "Squash and merge: PR #142?". In PR detail the picker lists only the methods the repository allows, the first is the default, and `m` then Enter merges it (the picker names the PR and the footer shows `[Enter] <method>`); `e` opens the optional commit message step first. `OptionPicker` gains `promptKey` and `initialIndex`, and its message step now shows the title and a bordered input. `FormCompose` submits on Enter from the last text field, so Enter approves. `ConfirmDialog` uses theme tokens and the same border and padding as the picker.
- **Regression test:** `src/features/prs/detail-merge.test.jsx` (all five tests failed before the fix), `src/components/dialogs/OptionPicker.test.jsx` > `OptionPicker promptKey and initialIndex`, `src/components/dialogs/FormCompose.test.jsx`.
- **Sibling sweep:** The list pane merge flow (`list-dialog-view.jsx`) got the labels only; its `m`, Enter, Enter, confirm sequence still needs `promptKey` and a one-step confirm (list lane owns that file). Not done here: the three box styles in issue detail and the command palette, the missing `[DIALOG]` badge on list-view merge and close-issue confirms, and the two hint bars in detail views (issues lane and the focus-manager refactor, #484).
