# nvim pr-for-branch always returns null: gh pr list rejects reviewThreads (#438)

- **Area:** executor (branches)
- **Symptom:** The nvim `pr-for-branch` IPC request always answered `{ prNumber: null }`, even when the branch had an open PR.
- **Root cause:** `getPRStateForBranch` passed `reviewThreads` to `gh pr list --json`. gh rejects that field ("Unknown JSON field"), `runGh` threw, and the `catch` returned `{ prNumber: null }` with no log, so the failure was silent.
- **Fix:** In `src/executor/branches.js`, drop `reviewThreads` from `--json` and remove the unresolved-thread count, so `unresolvedThreads` is no longer returned (JSDoc updated). The `catch` now logs through `logger.error` before returning `{ prNumber: null }`. `src/ipc.js` doc comments no longer promise `unresolvedThreads`.
- **Regression test:** `src/executor.test.js` › getPRStateForBranch (#438) › getPRStateForBranch only requests fields `gh pr list --json` accepts (failed before the fix: `reviewThreads`). The companion test `resolves { prNumber: null } when runGh rejects` guards the fallback and passes both before and after.
