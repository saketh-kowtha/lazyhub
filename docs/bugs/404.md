# Issue detail posts an empty comment on Enter with a blank reply (#404)

- **Area:** issues
- **Symptom:** Pressing `c` then Enter with an empty or whitespace-only reply posted a blank comment via `addIssueComment` and closed the reply box.
- **Root cause:** `doReply` in `src/features/issues/detail.jsx` sent `replyText` without checking it for content.
- **Fix:** `doReply` trims the text; if empty it shows "Reply cannot be empty", keeps the reply box open and posts nothing.
- **Regression test:** `src/features/issues/issues.test.jsx` › `issue detail empty reply` › `does not post an empty reply and keeps the reply box open` (and the whitespace-only variant); both failed before the fix.
- **Sibling sweep:** PR comment reply/edit (`src/features/prs/comments.jsx` `submitAction`) and diff compose (`src/features/prs/diff/state.js`) already trim and skip empty bodies; no change needed. Other panes have no free-text comment path.
