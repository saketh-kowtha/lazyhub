# A key handler that threw ended the session; ErrorBoundary could only re-render the same crash (#490)

- **Symptom:** an exception in a key handler is raised from a stdin event, outside React's render, so no ErrorBoundary saw it and the process-level crash handler exited the app. The boundary's own "dismiss" re-rendered the same subtree, and its colours were hard-coded.
- **Fix:** `src/contain.js` wraps handlers: a throw or rejected promise is logged with its scope and shown as a six-second toast in the status bar. `src/hooks/useSafeInput.js` exports Ink's `useInput` through that wrapper and every app file now imports it (lint and a source scan keep it that way). `ErrorBoundary` takes colours from `useTheme()` and gains `r` to remount its subtree with fresh state; Enter/Esc still dismiss.
- **Left:** per-pane-section boundaries, and replacing the remaining silent `catch {}` blocks on UI paths with a `logSwallowed` helper (R12 scope not done here).
- **Regression tests:** `src/contain.test.jsx`.
