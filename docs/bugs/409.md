# Actions and Notifications lose the cursor when a refetch shrinks the list (#409)

- **Area:** actions, notifications
- **Symptom:** After a refetch returned fewer rows (e.g. mark-read removing the last notification), the cursor pointed past the end: no row highlighted, and Enter / X / u acted on nothing.
- **Root cause:** `cursor` and `scrollOffset` are local state that was never re-clamped when `items.length` decreased. #379 fixed this for Issues only.
- **Fix:** A `useEffect` on `items.length` in `ActionList` and `NotificationList` clamps the cursor and scroll offset to the last row (same shape as #379).
- **Regression test:** `src/features/actions/actions-cursor.test.jsx` › `keeps a valid selection when a refetch returns fewer runs`; `src/features/notifications/notifications.test.jsx` › `keeps a valid selection when a refetch returns fewer notifications` (both failed before the fix).
- **Sibling sweep:** Issues fixed in #379. PRs list (`src/features/prs/list.jsx`) and Branches (`src/features/branches/index.jsx`) have no equivalent clamp on `items.length` shrink; they are owned by other agents and were not touched, so they likely need the same fix.
