# Homebrew tap stayed on 26.5.4 while npm latest moved to 26.6.2 (#472, repo side)

- **Symptom:** the tap formula pointed at `lazyhub-26.5.4.tgz` and its test expected `--version` to exit 1; `brew upgrade` never reached 26.6.x.
- **Root cause (from the workflow history):** the tap is only ever updated inside `promote.yml`, behind the dist-tag move. The only Promote run on record (2026-10-30) failed at "Verify package is on next" because 26.6.2 was already `latest` and there was no `next` tag, so it stopped before the Homebrew step, and no rerun was possible for a version that is not on `next`. Separately, a missing `TAP_TOKEN` skipped the push with only a warning, so a promotion could go green with the tap left behind. Nothing compared the tap with npm, and `docs/homebrew.md` still said `release.yml` did the push.
- **Fix:**
  - `promote.yml` accepts a version that is already `latest` (skips the dist-tag step, still updates the tap), requires `TAP_TOKEN` before the dist-tag moves instead of skipping silently, renders the formula from `packaging/homebrew/lazyhub.rb.tmpl`, and ends with `node scripts/homebrew-formula.mjs check --wait 120`, which fails unless the tap carries the npm `latest` version.
  - The formula test is now `assert_match version.to_s, shell_output("#{bin}/lazyhub --version")` (exit 0). The template and its rendering are unit-tested.
  - `.github/workflows/tap-check.yml` runs the same read-only comparison every Monday and on demand. Run `node scripts/homebrew-formula.mjs check` locally: against the live tap today it exits 1 ("the Homebrew tap is on 26.5.4 but npm latest is 26.6.2").
  - `docs/homebrew.md` and `docs/RELEASING.md` describe the real flow.
- **Left (Part of #472):** the tap itself is still on 26.5.4. Nothing was pushed to the tap, published or tagged here. The bump happens by running `Promote` for 26.6.2 (it now works for a version that is already `latest`) or on the next release; `TAP_TOKEN` must be available to that job. The workflows themselves were not run (they need secrets and the `npm-publish` environment).
- **Regression test:** `src/release-tap.test.js`.
