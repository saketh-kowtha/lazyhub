# PR list did not refresh after approve or request changes (#439)

- **Symptom:** after approving or requesting changes from the PR list, the row's review state stayed stale until `r`.
- **Root cause:** the `reviewPR` success path in `list-dialog-view.jsx` called `showStatus` but never refreshed the row.
- **Fix:** it now calls `refreshPR(number)`, which re-reads just that PR and patches its row; the loaded pages are not reset. A failed review does not refresh.
- **Regression tests:** `src/features/prs/list-dialog-view.test.jsx`, `src/features/prs/list-paging.test.jsx` ("writes patch the row").
