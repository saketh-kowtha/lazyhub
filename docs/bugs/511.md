# Advertised keys that do not work: hints, help and chords that lie (#511)

- **Area:** app | prs | actions | dialogs
- **Symptom:** checks mode said `[R] rerun` and `[l] annotations` (neither works; the keys are Ctrl+R and Enter); `g l` in the diff did nothing; `/` was listed for the Actions pane but dead; picker footers said `Ctrl+g/G` (the keys are Ctrl+T / Ctrl+B); the leader hint offered `r recent` (a stub); the sidebar footer said `S cfg`, `E edit`; the palette showed `Checkout [b]` and `Copy URL [y]` in PR detail, where they are not bound; "Global (any view)" in help listed Tab, `,`, `r`, `o`, `/`, which full-screen views ignore; `V` toggled a VISUAL mode nothing consumed.
- **Root cause:** hint strings were typed by hand next to the handler, so they drifted from the registry. `useActionResolver` joined chord tokens without a space (`gl`) while the TOML declares them with one (`g l`). The Actions pane had no `/` handler but shared the list scope.
- **Fix:** `hintLine()` / `effectiveHintKey()` (`src/config/actions.js`) render hints from the effective bindings; checks mode, PR detail hint lines, MultiSelect and FuzzySearch footers, the leader hint and the sidebar footer use them. The chord resolver tries both spellings. The Actions pane implements `/` with the shared FuzzySearch. The palette shows a key only in contexts where it is bound. The global help block lists only what `app.jsx` handles in every view; Tab and `,` are added for list views only. The `r recent` stub and the `V` visual toggle are removed (actions deleted from the defaults; `legacy-defaults.js` regenerated).
- **Regression test:** `src/keys.e2e.test.jsx` (checks hints and Ctrl+R/Enter, `g l`, Actions `/`, picker Ctrl+T/Ctrl+B, leader hint, global help block), `src/components/Sidebar.test.jsx` > "Sidebar footer key hints", `src/ui/actions.keys.test.js` (each failed before the fix).
- **Sibling sweep:** `/` in PR comments, issue detail and tab lists is already filtered out of help (`UNSUPPORTED`); PR list, issues, branches, notifications and diff handle it. The PR preview popover hint now reads `Esc hide` (the `[p] close` text no longer exists).
