# Claims check: PR description claims were never compared with the diff (#361)

- **Area:** prs
- **Symptom:** "Fixes #88", "adds tests" or "no breaking changes" in a PR description had to be checked by hand.
- **Root cause:** nothing extracted claims from the title and description or compared them with the changed files.
- **Fix:** `src/features/prs/claims.js` (pure extractor and verifiers), `src/executor/claims.js` (read-only data), `src/features/prs/ClaimsView.jsx` (PR detail key `V`). Each claim is verified, contradicted or unverifiable with file and line evidence. Deterministic only: the optional AI pass is not part of this slice (`Part of #361`). The PR text is untrusted (THREAT_MODEL T3, T4, T20): cleaned with `sanitizeBlock`, only matched by linear patterns, never executed or sent to a model.
- **Regression test:** `src/features/prs/claims.test.js` (all claim types, injection prose, escape-only input, huge bodies), `src/features/prs/ClaimsView.test.jsx`, `src/executor/claims.test.js`.
- **Sibling sweep:** issue detail has no equivalent description claims; not applicable.
