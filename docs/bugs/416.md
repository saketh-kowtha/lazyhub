# Branches pane hid fetch errors and lost the cursor when the list shrank (#416)

- **Area:** branches
- **Symptom:** a failed branch fetch showed "No branches found"; after deleting a branch the cursor pointed past the end, so no row was selected and keys did nothing.
- **Root cause:** `BranchList` never rendered `error` from `useGh` (empty state only checked `!loading && items.length === 0`), and nothing re-clamped `cursor` when `items.length` dropped.
- **Fix:** render `FailureNotice` plus a retry hint on error and suppress the empty state; a `useEffect` on `items.length` clamps cursor and scroll offset (same as Issues #379 and Notifications #370).
- **Regression test:** `src/features/branches/index.test.jsx` › `shows the failure and a retry hint instead of "No branches found" when the fetch fails` and `keeps a valid selection when a refetch returns fewer branches` (both failed before the fix).
- **Sibling sweep:** Issues (#379), Notifications (#370) already fixed; PRs and Actions panes are owned by other work and were not touched.
