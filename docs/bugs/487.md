# R9: list panes onto the shared list, query, mutation and row primitives (#487; #453, #460 slices)

- **Area:** actions | branches | issues | prs
- **Symptom:** four copies of the cursor, `gg` timer, clamp-on-shrink effect, loading/error/empty predicates and pending-write plumbing; Branches drew `▶` while every other row drew `▎`.
- **Root cause:** each pane hand-rolled its list code before the R8 primitives existed.
- **Fix:** Actions, Branches and Issues use `useListController` (cursor, `gg`/`G`, clamp with selection memory), `QueryBoundary` (skeleton, failure, empty), `useMutation` + `MutationStatus` (pending line, double-submit guard, sticky failure, invalidation) and `ListRow` (gutter glyph). PR rows use `ListRow`. Issues keep their status inline in the filter line and their overlay/cursor-paging logic. A failed Branches push now reads "Failed: ..." (was "Push failed: ...").
- **Regression test:** `src/ui/list-row-glyph.test.jsx` (guards #460); existing pane tests for Actions, Branches and Issues, with the Branches expectations moved from `▶` to `▎` and its `useGh` mock returning stable arrays (a new array each render looks like a refetch to the controller's selection memory).
- **Sibling sweep:** not migrated here: the PR list controller (saved cursor across back-navigation, preview panel, list dialogs), PR detail, PR diff, Comments, Logs, CustomPane, ConflictView, Focus tab view. `lastKeyRef` remains in `prs/list.jsx` and `components/CustomPane.jsx`.
