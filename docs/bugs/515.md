# MCP adapter: no repo validation, placeholder tool, hard-coded version, loose schemas (#515)

- **Symptom:** a call with no resolvable repo reached the executor with `null`; `lazyhub_query` was advertised but returned canned text; `serverInfo.version` was always `1.0.0`; every tool shared one schema with no `required`; `list_prs` returned full bodies, up to 50 checks per PR and pretty-printed JSON.
- **Root cause:** `src/daemon/mcp-adapter.js` shared one generic schema for all tools and never checked the resolved repo.
- **Fix:** `MCP_INVALID_REPO` when no repo resolves; a clear "requires a number" error; `lazyhub_query` removed; version read from `package.json`; per-tool `inputSchema` with `required`; `list_prs` drops `body`, caps checks at 10 (`checksTotal` reports the full count) and results are compact JSON. Contract: `docs/CONTRACT.md` MCP section. Regression tests: `src/daemon/mcp-adapter.test.js`.
