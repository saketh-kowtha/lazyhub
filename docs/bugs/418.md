# Branches pane rendered unsanitized branch names and a dead ahead/behind display (#418)

- **Area:** branches
- **Symptom:** a branch name containing a terminal escape sequence corrupted the row and dialogs; the `↑N ↓M` display never appeared.
- **Root cause:** `branch.name` was interpolated raw into rows, fuzzy items, checkout/delete dialogs and status messages (invariant 12). `aheadBy`/`behindBy` are never returned by `listBranches`, so the display was unreachable.
- **Fix:** every rendered or interpolated branch name goes through `sanitize()` (the raw name is still passed to `git checkout` and `deleteBranch`); the dead ahead/behind display is removed rather than adding a per-row compare call.
- **Regression test:** `src/features/branches/sanitize.test.jsx` › `strips terminal escapes from branch names in rows and the checkout dialog` (failed before the fix).
- **Sibling sweep:** other panes already sanitize their titles; Branches was the one pane missing it. Delete confirmation `requireText` now uses the sanitized name so it stays typeable.
