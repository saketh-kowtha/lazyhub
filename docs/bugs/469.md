# Error notices repeated per Focus pane and claimed a cached read with an empty cache (#469)

- **Symptom:** offline, every Focus pane printed the same full notice, and each said "Reading works from the cache" even when nothing had ever been cached.
- **Root cause:** `classifyGhFailure()` hard-coded the cache claim for the `offline` failure, and `TabPane` rendered a full `FailureNotice` for every failing pane.
- **Fix:** `classifyGhFailure(err, { cached })` now says "Showing the last loaded data" only for `cached === true`, "Nothing is cached yet" for `cached === false`, and makes no cache claim when the caller does not know. `TabPane` passes `cached: data != null`. `TabView` tracks which panes fail; the first prints the full notice and later ones use `FailureNotice compact` (cause line only).
- **Regression test:** `src/features/tabs/notice.test.jsx` (80x24 and 120x40, plus the classifier contract).
- **Not covered here:** the PR detail header repeating the raw error, the issue-detail close key and the first-run report jargon from the same ticket live in `src/features/prs/**` and other lanes.
