# Actions pane renders workflow and branch names without sanitize() (#414)

- **Area:** actions
- **Symptom:** A run named `Build &amp; Test` showed the literal `&amp;` in the list row and in the Cancel-run confirmation; ANSI/control characters in names would reach the terminal.
- **Root cause:** `ActionRow` and the Cancel dialog interpolated `run.workflowName` / `run.headBranch` raw (the Re-run dialog already used `sanitize()`).
- **Fix:** Wrapped workflow name, head branch, and the branch-filter labels in `sanitize()`. The pane shows no job names (logs are already ANSI-stripped).
- **Regression test:** `src/features/actions/actions-sanitize.test.jsx` › `decodes entities in the run row` and `decodes entities in the Cancel-run confirmation` (failed before the fix).
- **Sibling sweep:** Notifications already sanitizes the title; its `repository.name` and `reason` are rendered raw but are GitHub-constrained identifiers/enums (not touched). PRs/Issues/Branches are owned by other agents.
