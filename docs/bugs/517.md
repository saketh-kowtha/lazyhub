# First run showed a jargon governance report before any PR (#517)

- **Symptom:** after picking a repo on first launch, a "Coverage (github_enforced | managed_gateway | ...)" report appeared (two Enters, 6-10 s with real gh, footer truncated) before the first useful screen, Focus.
- **Root cause:** onboarding had a second "Report" step that observed the repo and rendered the doctor/watch-only coverage model with undefined vocabulary.
- **Fix:** choosing a repository now completes onboarding at once (one Enter reaches Focus); no gh observation runs before Focus. The report is offered on demand: the repo list shows a one-line tip pointing at `lazyhub watch-only`. A palette entry is not added (palette lives outside this change). `Report`, `loadOnboardingReport` and `explainGap` were removed; the `watch-only` command is unchanged. The config-file write (#475) is untouched. Regression tests: `src/features/onboarding/Onboarding.test.jsx` (one Enter completes, no report, no graphql read) and the PTY scenario `runFirstRunFlow` in `test/pty/run.js` (first run reaches Focus after one key, no governance text).
