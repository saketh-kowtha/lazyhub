# AI on existing subscriptions without the sandbox losing its guarantees (#364)

- **Area:** config | ai
- **Symptom:** users with a Codex ChatGPT login had no way to use it; the #252 sandbox only accepts API keys. Error messages also copied the first stderr line of the CLI.
- **Root cause:** the sandbox deliberately withholds the real HOME, and `_base.js` put `stderr` text into `Error.message`.
- **Fix:** `src/services/ai-cli.js` is the single spawn point (process group, caps, stderr never surfaced). Opt-in, capability-gated `login` profile for Codex. See D18, `docs/AI_PROVIDERS_SPEC.md` section 14 and `docs/THREAT_MODEL.md`.
- **Regression test:** `src/services/ai-cli.test.js`, `src/ai/providers/codex.login.test.js`, spawn-site scan in `src/services/git.test.js`.
- **Sibling sweep:** claude-code and gemini-cli use the same error mapper (stderr no longer in messages).
