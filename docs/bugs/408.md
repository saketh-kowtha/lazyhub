# Branch delete broke on names with a slash; only 100 branches were listed (#408)

- **Area:** branches
- **Symptom:** deleting `feat/x` sent `git/refs/heads/feat%2Fx` and failed; repos with more than 100 branches showed only the first 100.
- **Root cause:** `encodeURIComponent` was applied to the whole ref name (also in `getRemoteBranch`, `compareBranches`, `getBranchProtection`), and `listBranches` made a single `per_page=100` request.
- **Fix:** new `encodeRefPath()` encodes each `/`-separated segment; `listBranches` follows `page=N` until a short page, capped at 10 pages (1000 branches).
- **Regression test:** `src/executor.test.js` › `branch names with slashes and paging` (both tests failed before the fix).
- **Sibling sweep:** every `encodeURIComponent(<ref>)` in `src/executor/` was converted; PR list already pages via its own `limit`.
