# Help overlay docs link is a 404 (#467)

- **Area:** help overlay (`src/app-panels.jsx`)
- **Symptom:** The Docs line in the `?` help overlay pointed to `https://saketh-kowtha.github.io/lgh`, which is a 404.
- **Root cause:** The URL used the old short project name `lgh`. The real docs site is at the `homepage` in `package.json`, `https://saketh-kowtha.github.io/lazyhub`.
- **Fix:** Replaced the URL with `https://saketh-kowtha.github.io/lazyhub` in `src/app-panels.jsx`. A repo-wide grep for `github.io/lgh` in `src`, `bin`, `docs` and `README.md` found no other hits.
- **Regression test:** `src/app-panels.test.jsx` › HelpOverlay docs link › shows the real docs URL on wide terminals (failed before the fix, passes after).
