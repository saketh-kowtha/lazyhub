# Settings pane shows "Theme: [object Object]" (#459)

- **Area:** settings, theme
- **Symptom:** The Settings pane's Theme row printed `[object Object]` instead of the theme name when the theme was set from the TOML `[theme]` table.
- **Root cause:** `app.jsx` passes `readRawThemeCfg()` (`{ name, overrides }` or `null`) as `initialTheme` to the legacy `ThemeProvider`. The provider stored that object as `themeName` and exposed it through context, and the Settings pane rendered it directly.
- **Fix:** In `ThemeProvider` (`src/theme.js`), the state now holds the full config (`themeCfg`) and is still passed to `resolveTheme`, so overrides still apply. The context exposes `themeName` as a string (`themeCfg.name`, falling back to `'github-dark'`).
- **Regression test:** `src/settings-theme.test.jsx` › shows the theme name when config.theme is the TOML table { name } (failed before the fix). Guard: `src/settings-theme.test.jsx` › still applies [theme] overrides when config.theme is the TOML table.
