# Rows, headers and overlays exceed the terminal width or height (#512)

- **Area:** app | notifications | issues | actions | branches | focus | prs
- **Symptom:** Notifications, Issues, Actions and Branches rows wrapped or ran past the right border with emoji/CJK titles or long names; the Focus dashboard sections overlapped and pushed the status bar out; the help overlay spilled below its own footer; the PR detail meta row wrapped every field onto its own line.
- **Root cause:** rows were flex rows of shrinkable `Text` cells with no width from the pane, so Yoga wrapped them. Separately, Ink measures BMP emoji (U+2705, U+2728, ...) as one cell while the terminal draws two, and measures ZWJ sequences per code point, so a title with a check mark pushed the border one column off. Ink has no `maxHeight`, so the help box and Focus sections never clipped.
- **Fix:** `src/ui/row-layout.js` is the width contract: `planRow` gives fixed cells their columns, the title the rest, and drops optional cells (labels, author, age, reason, branch) in order instead of wrapping; `fitCell` returns text of exactly N columns. `sanitize()` now runs `inkSafe()`, which removes joiners/variation selectors and follows BMP emoji with a zero-width space. The App passes `innerWidth` to the Issues, Actions, Branches, Notifications and Focus panes. Focus splits its height into per-section budgets (one section at a time, with a `section 2/3` marker, when three do not fit). The help overlay has an explicit height, one truncated line per row and a `+N more` line. The PR detail header uses one truncated row for the title and one for author, head -> base, diffstat and age.
- **Regression test:** `src/screen-matrix.e2e.test.jsx` (the `KNOWN_DEFECTS` pins for #428-#431 are removed; 60x20 added to the sizes), `src/app-panels.test.jsx` > "HelpOverlay height budget", `src/features/prs/detail/Header.test.jsx`, `src/features/branches/row-layout.test.jsx`, `src/ui/row-layout.test.js`.
- **Sibling sweep:** every list pane and the Focus dashboard are in the matrix at 50x15, 60x18, 60x20, 80x24, 120x40 and 200x50.
