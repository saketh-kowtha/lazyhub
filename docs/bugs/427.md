# PR diff shows &#x27; instead of apostrophes in highlighted code (#427)

- **Area:** prs
- **Symptom:** every single-quoted string in a highlighted diff line rendered as `&#x27;...&#x27;`.
- **Root cause:** `htmlToChalk()` in `src/features/prs/diff/highlight.js` decoded `&#39;` but highlight.js emits `&#x27;` for apostrophes.
- **Fix:** also decode `&#x27;`.
- **Regression test:** `src/screen-matrix.e2e.test.jsx` › `screen matrix: real App against fixtures` › `pr-diff` at 60x18 and up (the `entity` invariant was pinned with `it.fails` in the previous commit and failed before the fix).
- **Sibling sweep:** the other panes render API text, not highlighter output; `&amp; &lt; &gt; &quot;` were already decoded.
