# lazyhub looks dull and low-contrast next to other terminal UIs (#566)

- **Area:** app (theme), prs, issues, branches, actions, notifications
- **Symptom:** On a truecolor terminal the UI looked faded next to lazygit, k9s and btop: hints and metadata were barely readable, borders were nearly invisible, rows used a different colour for state, CI, review, labels and age, and the default palette ignored the terminal's own scheme.
- **Root cause:** (1) the default theme was GitHub's website hex palette, tuned for a `#0d1117` page; (2) `ui.dim` `#484f58` is about 2:1 on dark backgrounds and is used for hints and metadata, and four sites also added Ink's `dimColor` on top; (3) `border` `#30363d` and `divider` `#21262d` (and Catppuccin Mocha's `#1e1e2e` divider on a `#1e1e2e` background) are below any visibility threshold; (4) two theme systems, `src/theme.js` (`t.*`) and `src/theme/` (`scheme.*`), with different palettes, so the PR list looked unlike every other pane; (5) rows coloured author, age, labels and state independently; (6) the aurora themes named syntax keys the highlighter never reads, so light Aurora inherited dark GitHub syntax colours.
- **Fix:** New default `terminal` theme from the 16 ANSI named colours (bold accent plus the gutter glyph for selection). Every hex theme declares `ui.bg`/`ui.fg` and passes a WCAG floor (text and state 4.5:1, muted and dim 3:1, borders 1.8:1). One theme system: `src/theme/` schemes and tokens are folded into `t.*`; `useTheme()` returns `t` plus a derived `scheme` view; `bg-detect.js` stays and picks the hex theme for `theme = "auto"`. Rows use one accent for the focused row, muted for the rest, state by glyph, and red/yellow only for failing or pending CI, changes requested and conflicts. The pane header no longer draws a rule inside the pane's own box.
- **Regression test:** `src/themes/contrast.test.js` (failed before: 69 cases, including `github-dark ui.dim #484f58`); `src/lint-invariants.test.js` › no double dimming (failed before: 4 sites); `src/theme.test.js` (terminal theme is ANSI-only, default, complete); `src/row-colour-budget.test.jsx`; `src/screen-matrix.e2e.test.jsx` › NO_COLOR stays readable; `src/app-panels.test.jsx` › PaneHeader.
- **Sibling sweep:** PR, issue, branch, action and notification rows all follow the same colour budget and now have the focus gutter glyph. Detail views, the diff and dialogs were not restyled; `src/features/prs/list-dialogs.jsx` still imports `useTheme` through the `src/theme/index.js` re-export (another change owns that file).
