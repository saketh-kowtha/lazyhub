# IPC: a JSON line that is null crashes the TUI (#437)

- **Area:** ipc
- **Symptom:** A client that sent a well-formed JSON line whose value is not an object (`null`) crashed the TUI process with an uncaught exception.
- **Root cause:** `handleMessage` in `src/ipc.js` parsed the line and destructured `{ id, type }` from the result without checking the type. `JSON.parse('null')` returns `null`, and destructuring `null` throws. Parse errors were already caught; non-object values were not.
- **Fix:** In `src/ipc.js`, right after the `JSON.parse` try/catch, ignore any parsed value that is not a plain object: `if (!msg || typeof msg !== 'object' || Array.isArray(msg)) return`.
- **Regression test:** `src/ipc.test.js` › IPC message validation › a well-formed JSON line that is not an object (null) must not crash the process (also covers `5`, `"str"` and `true`; the null case failed before the fix).
