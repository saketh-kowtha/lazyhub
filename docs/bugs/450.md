# Digit pane-jump fired after the leader and in detail views, and help over-promised it (#450)

- **Area:** keys, help
- **Symptom:** `<Space>` then a digit jumped panes; an accidental `1` in PR detail jumped to Focus; help listed `1-9` under "Global (any view)" although digits were dead in diff, comments and settings.
- **Root cause:** `app.jump-pane` ran before the leader block and accepted `detail` views; the help overlay always rendered it with the global keys.
- **Fix:** Recorded decision (2026-10-31): digits jump panes from list views only. `app.jsx` requires `view === 'list'` and no active leader. Help shows `1-9` first in a list view's own key column and never in other views (`LIST_VIEW_KEYS` in `app-keys.js`). Action description and `docs/mockups/keymap-canonical.md` agree.
- **Regression test:** `src/app.e2e.test.jsx` › number keys do nothing in a detail view; a digit after the <Space> leader does not jump panes; help lists 1-9 under the list view keys (all failed before the fix).
