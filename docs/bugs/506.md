# Issues list could never show more than page_size issues (#506)

- **Symptom:** in a repo with 1,000 open issues the list stopped at `page_size` with no way to load more and no indicator.
- **Root cause:** `IssueList` called `listIssues` with a fixed `limit` and had no load-more path; the list payload also requested the full `comments` array for every row.
- **Fix:** new `listIssuesPage` (GraphQL search, cursor + `issueCount`, comment count only). `IssueList` keeps the first page in `useGh` and fetches later pages by `endCursor` as the cursor nears the end, appending without refetching earlier pages (`r` resets). A footer shows `N of M`, `loading more…`, a failed-page notice, or the GitHub 1,000-result cap. `listIssues` (dashboards, MCP) no longer requests `comments`.
- **Regression test:** `src/features/issues/issues.test.jsx` ("issue list load-more"), `src/executor/issues.page.test.js`.
