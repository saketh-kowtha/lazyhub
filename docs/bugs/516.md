# Contradictory wording across CONTRACT, SECURITY, AGENTS, package.json and the Homebrew doc (#516)

- **Symptom:** several documents described behaviour the runtime does not have: the MCP table in `docs/CONTRACT.md` listed mutating tools and aliases as working although the server refuses them with `MCP_MUTATIONS_DISABLED`; `SECURITY.md` said AI is off by default although AI review is on and a provider is detected (data is sent only when a feature is invoked); `AGENTS.md` invariant 4 said the `gh` environment is curated although the executor deliberately inherits it; the `package.json` description promised "every GitHub action"; `docs/homebrew.md` showed a 0.2.1 URL; the review-evidence section did not say that no UI consumes it yet.
- **Fix (docs only, no behaviour change):** `docs/ARCHITECT_DECISIONS.md` stays the authority for invariant wording and `AGENTS.md` now matches it (curated env for AI subprocesses; the `gh` executor inherits the user's `gh` environment and must not be stripped). `docs/CONTRACT.md` splits the MCP tables into advertised read-only tools and refused names. `SECURITY.md` describes AI as available but never sent until invoked, and the Alpha as review-first. The `package.json` description and the Homebrew example no longer promise more than the product does. The evidence section states its status.
- **Guard:** `src/docs-sync.test.js` checks both CONTRACT tables against `TOOLS`, `TOOL_ALIASES` and `MUTATING_TOOLS` in `src/daemon/mcp-adapter.js`, and the shared invariant wording, so these cannot drift again.
- **Not changed:** `README.md` (covered by #285).
