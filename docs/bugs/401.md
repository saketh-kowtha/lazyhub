# Layout breaks on resize and in small or multiplexer panes (#401)

- **Area:** app
- **Symptom:** After resizing the terminal, or in a small/odd-sized multiplexer pane (herdr, tmux), the layout tears: the sidebar keeps its width, footer hints wrap and push the frame taller than the terminal, the help overlay overlaps the previous frame, the preview covers the list, stale cells stay after shrinking, and `retry` is cut from the degraded banner at 80 columns. No minimum-size handling.
- **Root cause:** Nothing re-rendered React on the stdout `resize` event (Ink re-lays-out the old tree only), so `useLayout` kept the old size; `_cfg.sidebarWidth ?? bp.sidebarWidth` let the always-populated config default beat every breakpoint; `FooterKeys` used `flexWrap="wrap"` and `StatusBar`/`PaneHeader`/`TabStrip` had no truncation; `HelpOverlay` used fixed 40/38-column panes.
- **Fix:** New `useTerminalSize` hook (debounced resize, clear on change, auto-wrap off during the transition). `useLayout` is now a pure `computeLayout()` with breakpoints (narrow/medium/wide/ultrawide/too-small) that treats `[layout]` as preferences. New `TooSmall` view. `FooterKeys` fits to width and drops trailing keys; `StatusBar` is one row and keeps the retry hint; `PaneHeader`, `TabStrip`, `Sidebar`, `HelpOverlay` truncate/clamp; the PR hover preview collapses when it does not fit. Documented in `docs/DESIGN_REVAMP.md` §15 and `docs/mockups/responsive-layout.md`.
- **Regression test:** `src/responsive.e2e.test.jsx` (frame width/height at ten sizes, breakpoints, too-small, live shrink/grow and resize burst), `src/hooks/useLayout.test.js`, `src/components/FooterKeys.test.jsx`, and `test/pty/run.js` › `runResizeFlow` / `runTmuxResizeFlow` (all failed before the fix).
- **Sibling sweep:** Checked all panes (focus, prs, issues, branches, actions, notifications), PR detail, diff, help overlay and command palette at 200x50 down to 50x15 and too-small sizes. Remaining, outside this change: the PR detail meta line and hint lines in `src/features/prs/detail.jsx` still wrap below ~80 columns.
