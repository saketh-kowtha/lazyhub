# PR diff view emits raw TAB characters (#426)

- **Area:** prs (diff)
- **Symptom:** tab-indented code wrote a literal U+0009 to the terminal; gutter, right edge and wrapping were wrong.
- **Root cause:** diff row text went to the renderer unchanged; Ink and string-width do not treat TAB as a tab stop.
- **Fix:** `expandTabs()` (tab stops, default width 4; no config key exists) applied in `syntaxHighlight` and the hunk and tree-preview text in the diff render layer. `sanitize()` is unchanged.
- **Regression test:** `src/features/prs/diff/highlight.test.js` › "expands tabs to the next tab stop", "emits no raw TAB from syntaxHighlight, with or without a language" (failed before the fix).
- **Sibling sweep:** PR comments and issue bodies render through other paths; not changed here.
