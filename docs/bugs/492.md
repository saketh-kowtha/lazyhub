# Focus PR detail loses the comments action after returning from the diff (#492)

- **Area:** app
- **Symptom:** Open a PR from Focus, press `d`, then Esc: back in detail, `v` did nothing even though the footer advertised comments. Reopening the PR restored it.
- **Root cause:** `goToDiff` replaced `selectedItem` with the PR object fetched by detail, discarding the dashboard `_kind`; on return `detailKind` fell back to the pane (`focus`), so `app-views.jsx` omitted the PR callbacks (`onViewComments`, `onOpenActions`, `onPaneState`).
- **Fix:** Already fixed on `main` by #493 (`goToDiff` keeps `_kind` and `_repo` from the previous item). This change adds the missing journey regression test.
- **Regression test:** `src/focus-repository.test.jsx` > `keeps the comments action after inspecting the diff and returning to detail (#492)`.
- **Sibling sweep:** Issue detail opened from Focus goes through the same `detailKind`; it keeps `_kind` the same way and is covered by the existing `opens a dashboard issue` test.
