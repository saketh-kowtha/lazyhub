# Actions pane shows "No workflow runs found" when listing runs fails (#403)

- **Area:** actions
- **Symptom:** A failed run-list fetch (auth, network, rate limit) rendered the empty state, hiding the failure and its fix.
- **Root cause:** `ActionList` read `error` from `useGh` only for `onPaneState`; the render never used it, and the empty state was gated on `!loading && items.length === 0`.
- **Fix:** Render `FailureNotice` plus a retry hint when `error` is set and suppress the empty state, mirroring Notifications (#371).
- **Regression test:** `src/features/actions/actions-error.test.jsx` › `actions list failures` › `shows the failure and a retry hint instead of "No workflow runs found" when the fetch fails` (failed before the fix).
- **Sibling sweep:** Notifications (fixed in #371), PRs and Issues list views already use `FailureNotice`. Branches is owned by another agent and was not touched.
