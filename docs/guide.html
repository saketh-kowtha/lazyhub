Install

You need Node.js 20 or later and the GitHub CLI (gh).

# npm
$ npm install -g lazyhub

# Homebrew (use the full name)
$ brew install saketh-kowtha/tap/lazyhub

# no install
$ npx lazyhub

This is saketh-kowtha/lazyhub, not the unrelated Go project ryo-ma/lazyhub that also documents a Homebrew tap. Published npm and Homebrew versions can lag the repository's main branch. If a feature on this site is missing, compare lazyhub --version with the releases and check lazyhub --help.

First run

  1. Run lazyhub. It checks that Node is new enough, that gh is installed and that you are signed in. Each failure prints one line saying what is wrong and the exact command to fix it, never a stack trace.
  2. Inside a clone of a GitHub repository, lazyhub uses that repository. Elsewhere, on the first interactive run, a short picker lets you search your repositories or type owner/name. When setup completes it writes ~/.config/lazyhub/lazyhub.toml. Cancelling saves nothing.
  3. You land on Focus: PRs waiting for your review, your open PRs and issues assigned to you. Press g q for the review queue, ? for help in any view, q or Esc to go back.

Rerun the picker any time with lazyhub --onboarding.

Sign in

lazyhub has no login of its own: it uses the account gh is signed in to.

$ gh auth login
$ gh auth status
  • An interactive launch with no session can start the gh login flow for you.
  • In scripts and CI, set GH_TOKEN instead.
  • With several accounts, switch with gh auth switch; lazyhub follows the active one.
  • Behind SAML SSO, lazyhub tells you when an organization has not authorized your token and prints gh auth refresh -h github.com.

Launching in and out of a repository

CommandWhat it does
lazyhubOpens the repository of the current directory (from its git remote). Outside a repository, uses the repository saved by first-run setup, else the picker.
lazyhub --repo owner/nameOpens that repository for this launch only. It is not saved and it wins over the directory's remote.
lazyhub owner/repo#123Opens a pull request or issue directly. Also accepts '#123', 123 or a PR or issue URL.
lazyhub --onboardingReruns the first-run setup. Cannot be combined with --repo.
lazyhub --mouseEnables mouse scrolling.

To switch repositories without restarting, press : and run "Switch repository". Precedence at startup is: --repo, the repository picked in a first-run flow, the repository detected from the current directory, the saved [defaults].repo, then the picker. A saved repository is only a fallback.

Remotes on GitLab, Bitbucket and other non-GitHub forges are ignored. If a clone has only a non-origin remote (such as upstream), lazyhub falls back to it.

Review a pull request

  1. Press g q. Each row says why the PR needs you. ] and [ change status group. Launched inside a clone, the queue shows that repository; s switches to your whole account, an organisation or a repository set (see [queue]).
  2. Press Enter to open its evidence: facts with their source and read time. From there d opens the diff and Enter the full PR. Esc returns you to the queue where you were.
  3. From a PR, f shows why CI is red, V checks the description's claims against the diff, K lists open PRs that touch the same files and s walks the diff step by step.
  4. Press d for the diff, c to comment, and a, x or m to approve, request changes or merge. Writes you start yourself ask for confirmation first.

The queue, evidence, claims, collisions, story and why-red views are read-only and show unknown when GitHub did not return a fact. In the PR list, Enter opens the plain detail. To have it jump to a failing check log, Files changed or the merge conflict instead, set smartEnter = true under [state] in your config.

GitHub Enterprise Server

$ gh auth login --hostname github.example.com
$ cd ~/work/some-clone          # remote on github.example.com
$ lazyhub

# outside a clone, or to be explicit
$ GH_HOST=github.example.com lazyhub --repo owner/name

lazyhub resolves the remote's host (including SSH aliases) against the hosts gh is signed in to. With --repo inside a clone whose host gh is not signed in to, it prints a note and uses github.com; set GH_HOST for Enterprise. A saved default repository is ignored when GH_HOST differs from the host it was saved under.

AI and MCP

  • lazyhub ai status shows which AI provider is usable and why. AI runs a CLI you already have (claude, codex, gemini) in a sandbox using an API key or token from the environment.
  • lazyhub ai login enable codex opts in to using Codex's own signed-in subscription (asks for typed consent); disable revokes it. For Claude, run claude setup-token and export the token. Gemini login mode is not implemented.
  • lazyhub --mcp (or lazyhub mcp-server) is a stdio MCP server with read-only tools for pull requests, diffs, checks, issues, notifications and branches. It never prompts and writes nothing to GitHub. Review-queue, evidence and why-red MCP tools are not shipped yet. See the contract.

doctor and the other commands

CommandUse
lazyhub doctor [--json]Checks the config file, that gh is installed and signed in, and prints review-coverage evidence. Safe on a fresh machine: it creates nothing.
lazyhub doctor --coverage --repo owner/nameLocal, read-only report of what lazyhub could observe. It does not approve, block or enforce anything.
lazyhub watch-only --repo owner/nameRead-only report of GitHub-visible PR activity.
lazyhub statusPrints review, CI and notification counts for a status bar. Exits 0 on a cold cache.
lazyhub feedback [--print]Opens a pre-filled GitHub issue with redacted diagnostics. Nothing is sent until you submit it.
lazyhub perf reportSummarizes timings recorded locally with LAZYHUB_PERF=1.
lazyhub serve [--status|--stop]Manages the optional background daemon.

Troubleshooting

lazyhub: command not found after installing

Open a new terminal or run hash -r. Make sure the npm global bin directory (run npm prefix -g, then look in its bin folder) is on your PATH.

"needs Node.js 20 or newer"

Install a current Node from nodejs.org or with nvm install 20.

"gh is not installed" or "too old"

Install or update the GitHub CLI from cli.github.com (macOS: brew upgrade gh). lazyhub prints the command for your system.

"You are not signed in to GitHub"

Run gh auth login (add --hostname for Enterprise). A revoked token that still looks present is reported this way too.

"Cannot reach api.github.com", rate limit, or gh did not respond within 10s

Check your network or proxy. For a rate limit, lazyhub says when to retry. A hung gh is usually a keychain prompt or slow credential helper waiting; run gh auth status in the same terminal.

"No repositories found" or "No repository selected"

Run lazyhub inside a clone, or pass --repo owner/name.

Garbled icons or colours

Set [ui].icons = "ascii" or NO_COLOR=1. ASCII icons are chosen automatically on TERM=linux, dumb and non-UTF-8 locales. If the terminal is smaller than 40 columns by 10 rows lazyhub shows a "terminal too small" notice instead of a broken layout.

A key does nothing

Press ?: the help overlay lists the keys for the current view. Digits 1 to 9 jump panes only from list views. Compare with the keybindings page, and check your config for a remapped key.

My config looks ignored

Run lazyhub doctor: invalid values are dropped with a warning and defaults fill in. See the config reference. Changes apply on the next launch.

Still stuck? Run lazyhub feedback, or open an issue.
